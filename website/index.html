Anonymous Dynamic Networks — Glossary

Agent
A computing entity in the network. Agents have no unique identifiers — they are anonymous. Each agent starts with an integer input value (0 = leader).
Leader
A special agent with input 0, shown as L in the simulator. Counting algorithms use the leader as a reference point to determine the total number of agents n.
Dynamic Network
A network whose communication links can change every round. Unlike static networks, edges are not permanent — they may be controlled by an adversary. The key challenge is that agents cannot rely on a fixed topology.
Round
One time step of communication. In each round a set of directed links is active and agents exchange messages only along those links. Use ↑ / ↓ or the scroll wheel to browse rounds in the simulator.
Interaction (Link)
A directed edge from agent A to agent B in a given round: A sends a message to B. The multiplicity counts how many parallel copies of the message are sent, which matters for the counting algorithms.
History Tree
A tree that records everything an agent has observed so far. The root is the initial state; each level adds one more round of observations. Two agents are indistinguishable if and only if they share the same history tree. The right panel of the simulator visualises this tree.
Anonymity Class
A group of agents with identical history trees — they cannot tell each other apart. The size of the class is its anonymity. An anonymity of 1 means the agent is uniquely identifiable by its history.
Counting Problem
The task of determining the total number of agents n. Because agents are anonymous they cannot simply count themselves — they must deduce n from the patterns of messages received over multiple rounds.
Stabilizing Algorithm
An algorithm that eventually outputs the correct answer and never changes it again, but may output wrong values before it stabilises. The simulator's stabilizing algorithm is guaranteed to stabilise by round 2n − 2. Select it with the Stabilizing button.
Terminating Algorithm
An algorithm that outputs the correct answer and then halts, explicitly signalling that it is done. This is a stronger guarantee than stabilizing: once it stops, the answer is provably correct. Select it with the Terminating button.
Outdegree Awareness
An optional capability (toggle with O) where each agent also knows how many messages it sent in the previous round. This extra information can help the algorithm make faster or more accurate guesses.
Exposed Pair
Two agents A and B such that A observes B and B observes A with matching multiplicities. Exposed pairs are the key mechanism the stabilizing algorithm uses to propagate anonymity estimates across the network.
