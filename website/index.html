Anonymous Dynamic Networks — Controls

Left-click + drag on agentDraw a new directed link from that agent
Right-click + drag on agentMove the agent
Right-click on empty areaCreate a new agent
Left-click on agent / nodeSelect / deselect
Mouse wheelChange current round

Modifiers while drawing or deleting a link

Ctrl or QDelete the link instead of creating it
ShiftMake the link two-way (bidirectional)
AltApply the change to all rounds
Caps LockToggle: two-way becomes the default direction

Navigation

↑ / ↓Previous / next round
← / →Previous / next distinguishable class in current Vista
ESCDeselect agents and clear Vista selection

Network Editing

Del or UDelete selected agent(s)
+Insert a new round after the current round
−Delete the current round
BackspaceDelete all links in the current round
0 – 9Set input of selected agent (0 = leader L)
LLoad network from file
SSave network to file
GSnap all agents to grid

Counting Algorithms (TAB cycles, Space steps)
